# Agent Instructions

1. Read `BOOT.md` first. It is generated by `tools/context/build_boot_context.py`; do not edit it by hand.
2. Read the startup bundle that `BOOT.md` names, then only the index views it lists.
3. Query full indexes with `tools/context/query_index.py`; never open them whole at startup.
4. Open large, raw or sealed files only through `tools/context/read_gate/read_context_file.py`.
5. Before changing startup, registry, index or governance files, run `./管家 我要改 <file>`.
6. After context edits, run `bash tools/context/run_context_governor_all.sh` and keep its verdict non-blocking.
